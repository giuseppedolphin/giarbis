To-do. La to-do di questa repo è un file markdown a caselle (`- [ ] testo`, con «P1», «P2», «P3» e «(entro GG/MM/AAAA)» facoltativi). Ogni voce ha un id corto (tipo `t3fa9c1`):
  {{ctl}} foglio todo "titolo" --descrizione "una riga"   → apre sulla mappa un foglio con le voci aperte, lette dal vivo
  {{ctl}} todo chiudi <id> "esito breve"               → spunta la voce e scrive la data e l'esito sulla stessa riga · todo riapri <id>
Quando {{persona}} ti chiede di segnare una voce come fatta usa "todo chiudi", mai a mano sul file; per aggiungere una voce scrivi una riga nuova a caselle in fondo al file. Il testo di una voce si legge con "foglio leggi" sul foglio della to-do, o aprendo il file.
